EffectKoja portable mode

While this file sits next to effectcraft.exe, EffectKoja keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EffectCraftData folder beside it instead of
%APPDATA%\EffectKoja. Copy the whole folder to move EffectKoja with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\EffectKoja unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\EffectKoja) instead.
If EffectCraftData can't be written (for example on a read-only drive), EffectKoja logs a
warning and uses %APPDATA%\EffectKoja instead.
